## 写在条款里的限制，下单前必须知道

这几条直接影响使用体验，但官网购买页不会主动提示你：

- **CPU 限制**：除 DC5 SLA 档外，20G E-Commerce 及香港/东京 40G 套餐的 1 小时平均 CPU 负载上限为单核 100%。跑持续高负载任务（编译、爬虫）会被限制，1GB 内存也决定了它只适合轻量应用。
- **迁移流量计入月度额度**：GIA-E 套餐虽然免费迁移，但迁移过程产生的数据传输会计入当月流量。频繁搬家的用户留意额度。

- **用途限制**：服务条款禁止开放代理（open proxies）和 Tor 中继节点；支持 tun/tap，常规自用 VPN 场景无碍。
